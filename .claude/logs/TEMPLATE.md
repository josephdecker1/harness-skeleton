# Session log — YYYY-MM-DD — <short description>

Copy this template per working session. Logs are cheap to write and they are what
memory files get distilled from. Write for a teammate who steps in tomorrow, not
for yourself an hour from now.

## Goal

What this session set out to do, as a verifiable outcome.

## What happened

The narrative. What you tried, what worked, what didn't. Cite evidence as
`path:line` or a command + its result — not "should work."

## Decisions

Anything a future session needs to know that isn't obvious from the diff. Each
with its rationale. Candidates for promotion to `.claude/memory/`.

## State at end

- Branch / PR:
- Verified working:
- **Incomplete / handed off:** what's left and the exact next steps (be honest —
  see `.claude/rules/definition-of-done.md`).
