# Rhetorical devices — the catalogue

Reference for rule 6 of `plain-language.md`. That rule is pass/fail: one device
means rewrite the line. This file names the twenty-five.

The order is a working guess at how often each shows up in model output. Nobody
measured it. Five have a gate in `plain-language-gates.md`. The rest need a
human read.

Quotations are exempt, including every example in the table.

| Device | What it looks like | Write instead |
|---|---|---|
| **Negation-correction** | "isn't just a config change", "not only X but Y" | Drop the negated half. State the claim. |
| **Framing tic** | "the point is", "here's the thing", "at the end of the day", "it's worth noting" | Delete the wind-up. Start at the claim. |
| **Sincerity filler** | "genuinely", "honestly", "frankly", "truly", "to be honest" | Delete the word. Honesty is the baseline. |
| **Litotes** | "not unlike", "not unexpected", "no small feat", "far from ideal" | State the positive claim. |
| **Em-dash aside** | An aside inside a sentence: "the fix works — mostly" | Use a period, a comma, or parentheses. |
| **Rhetorical question** | A question you then answer: "Why does this matter? Because…" | State the answer. |
| **Tricolon** | Three parallel items picked for rhythm: "faster, simpler, cheaper" | List only the items that carry information. |
| **Aphoristic closer** | A fragment ending a section for rhythm: "Same output." | Delete it, or fold it into the last full sentence. |
| **Fragment for emphasis** | "Every time." "Not once." | Use a full sentence. |
| **Colon-riff** | Setup, colon, payoff inside prose: "The result: cleaner code" | Write a plain sentence. List intros and labels stay. |
| **Escalating restatement** | The same point made three times with rising force | Make it once. |
| **Anaphora** | Consecutive sentences opening with the same words | Merge them or vary the opener. |
| **Coined metaphor as a label** | "interpretation debt", "the trust tax" | Use the literal description. |
| **Suspense ordering** | Holding the conclusion back for effect | Lead with the conclusion. |
| **Antithesis** | A balanced opposite: "the old way guesses, the new way measures" | State the one claim you can support. |
| **Isocolon** | Matched clause shapes: "less config, more control" | Keep the clause that carries the information. |
| **Chiasmus** | Mirrored word order: "tools for people, not people for tools" | Say it once, in one order. |
| **Asyndeton** | Conjunctions dropped for punch: "no fluff, no filler, no noise" | Use one item, or a plain list with "and". |
| **Anadiplosis** | An echo across the joint: "…builds trust. Trust that compounds." | Merge into one sentence without the echo. |
| **Sentence-initial conjunction** | "And that matters." "But the cache lies." | Fold into the prior sentence, or drop the conjunction. |
| **Staccato run** | Drumbeat sentences: "It ran. It failed. It always fails." | Keep short sentences that each add an idea. Cut the repeats. |
| **Doubled intensifier** | "very, very slow", "really, really annoyed" | Use the word once, or give the measurement. |
| **Decorative apposition** | Renaming a known thing: "Redis, the cache," on its tenth mention | Define a term at first mention only. |
| **Stacked hedges** | "arguably", "can potentially", "it could be argued" | Commit to the claim, or give the confidence and the reason. |
| **Nominalization** | "performed a validation of", "made a determination" | Use the verb: "validated", "decided". |

## Using it in review

Do not read all twenty-five before writing. Write, then scan the draft once
against four rows: negation-correction, framing tic, sincerity filler, and
tricolon. That shortlist is a judgement call.

The table earns its place in two situations. The first is a reviewer who needs
a name for what is wrong with a paragraph. The second is a writer who keeps
producing the same tic and needs to see it isolated.
